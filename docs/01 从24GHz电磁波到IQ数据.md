# 从 24 GHz 电磁波到 I/Q 数据

我们想做一个安装在房间里的小设备。

它不使用摄像头，也不要求人佩戴手环或标签。它只需要回答一个看似简单的问题：

> 房间里有人吗？

人可以用眼睛看、用耳朵听。但嵌入式设备没有天然的感官，它必须借助传感器，从外部世界获得某种物理线索。

摄像头利用光，麦克风利用声音，PIR 传感器观察红外辐射的变化。雷达采用另一种办法：

> 主动向房间发出一段已知的电磁波，再观察返回的波发生了什么变化。

这段看不见的波怎样从芯片进入房间？人体又怎样改变它？为什么雷达工作在 24 GHz，而微控制器（Microcontroller Unit，MCU）最后拿到的却是两串变化缓慢的 I/Q 数字？

让我们跟随一段雷达信号，看看它经历了什么。

```mermaid
flowchart LR
    A[波与频率] --> B[载波与波形控制]
    B --> C[天线发射]
    C --> D[传播与反射]
    D --> E[接收与混频]
    E --> F[I/Q与ADC]
```
